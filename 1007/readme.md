## 💡 자바스크립트 핵심 문법 & 개념 정리

본 저장소의 예제 코드를 공부하며 헷갈리기 쉬운 핵심 문법 요소 모음입니다.

### 1. `var` vs `let` vs `const` (변수 선언 방식의 차이)[cite: 6]

ES6 이전에는 `var`만 사용했으나, 예측하기 어려운 버그 방지를 위해 모던 자바스크립트에서는 `let`과 `const` 사용을 권장합니다[cite: 6].

| 구분 | `var` | `let` | `const` |
| :---: | :---: | :---: | :---: |
| **값 재할당** | 가능 | 가능 | **불가능 (상수/고정값)** |
| **재선언** | **가능** (버그 유발 원인) | **불가능** (에러 발생) | **불가능** (에러 발생) |
| **유효 범위 (Scope)** | **함수 단위 (Function)** | **블록 단위 (Block `{}`)** | **블록 단위 (Block `{}`)** |

* **왜 `var` 대신 `let`을 쓰게 되었을까?**
  1. **중복 선언 문제**: `var`는 동일한 이름의 변수를 또 선언해도 에러가 나지 않아 기존 값을 덮어쓰지만, `let`은 재선언 시 에러를 발생시켜 실수를 방지합니다.
  2. **유효 범위(Scope) 문제**: `var`는 `if`문이나 `for`문 내부에서 선언해도 블록(`{}`)을 뚫고 밖으로 나옵니다[cite: 6]. 반면 `let`은 선언된 `{}` 블록 내부에서만 안전하게 유효합니다[cite: 6].

```javascript
if (true) {
  var x = 10;
  let y = 20;
}
console.log(x); // 10 (밖에서도 접근 가능)
console.log(y); // ReferenceError: y is not defined (접근 불가)
