01. ABOUT ME

자기소개: 끝까지 집중해서 해결하는 개발자 지망생

소프트웨어학과 2학년 · 기초를 다지며 진로를 탐색하는 중

🎮 나의 강점

  • 오버워치 딜러 마스터 티어 (트레이서, 캐서디, 위도우, 소전, 한조 주력)
  • 순간적인 상황을 빠르게 판단하고, 실수하면 바로 고치는 집중력이 강점입니다.

💻 현재 배우는 것

  • 웹프로그래밍: 화면 구조(HTML), 꾸미기(CSS), 동작(자바스크립트) 기초
  • 자격증 준비: 네트워크관리사 2급, SQLD, 정보처리기사 로드맵 탐색

🧭 솔직한 진로 고민

  • AI 분야에 관심이 있지만 미적분 같은 어려운 수학에서 벽을 느꼈습니다.
  • 그래서 아직 진로를 하나로 정하지 않고, 실용적인 개발 기초부터 넓게 익히는 중입니다.
02. CONCEPT & REASON

프롬프트 공학이란? · 기능 · 사용한 이유

AI에게 원하는 답을 정확하게 받아내기 위한 질문 설계 방법

💡 프롬프트 공학이란?

  • AI는 수만 가지 데이터 중에서 내가 적은 조건과 가장 가까운 답을 찾아줍니다.
  • 게임에서 대충 쏘지 않고 적을 정확히 조준하듯, 조건(역할, 목적, 형식)을 콕 집어 질문하는 기술입니다.

🎯 왜 사용했을까? (이유)

  • 시간 절약: 수업 시간 50분 안에 웹사이트 뼈대를 빠르게 만들기 위해서입니다.
  • 학습 도우미: 어려운 코드 원리를 내 눈높이에 맞게 쉽게 풀어서 이해하기 위해 사용했습니다.
구분 핵심 내용
장점 코딩 속도가 매우 빨라지고, 모르는 문법을 바로 물어보며 배울 수 있습니다.
단점 AI가 가끔 틀린 코드를 알려줄 수 있고, 내가 이해하지 못한 코드는 고치기 어렵습니다.
차이점 "사이트 만들어줘"(단순 질문) vs "2학년 수준으로 주석 달아서 만들어줘"(구체적 지시)
03. EXAMPLES

사례 및 쉬운 예시 (내 코드 vs AI 코드 구분)

저작권 구분을 위해 직접 공부한 기초 예시와 AI 생성 실험을 나누어 정리했습니다.

✅ 사례 1: 수업 예제 기반 기초 실습

※ 수업 교재 코드를 참고해 직접 수정하고 원리를 익힌 내용입니다.

  • getElementById로 HTML 태그를 찾아 글자와 색깔 바꾸기
  • setInterval을 이용해 1초마다 움직이는 디지털 시계 만들기
쉬운 예시 1: 글자 바꾸기

여기가 바뀝니다!

// 핵심 코드 2줄
let name = document.getElementById("demoInput").value;
document.getElementById("demoText").innerText = name + "님 환영합니다!";

🤖 사례 2: AI(프롬프트)로 만든 실험 결과물

※ 내가 직접 짠 코드가 아니라, AI에게 조건을 주어 생성한 실험 결과물입니다.

  • 눈 내리는 샤갈의 마을: 오타를 고치고 주석을 달아달라고 요청해 이해함
  • 3D 은하계 시뮬레이션: 수학 공식이 복잡해 AI 생성 기능 테스트용으로 활용함
쉬운 예시 2: 랜덤 숫자 뽑기

행운의 숫자: ?

// 핵심 코드 2줄
let n = Math.floor(Math.random() * 100) + 1;
document.getElementById("numText").innerText = "행운의 숫자: " + n;

설치 방법 · 핵심 용어 · 요약 및 출처

오프라인 실행 방법과 발표 마무리 정리

⚙️ 설치 및 실행 방법

  • 별도 프로그램 설치가 필요 없는 HTML 파일 1개로 구성
  • USB에 담아 강의실 컴퓨터 크롬(Chrome)으로 열면 인터넷 없이도 바로 실행
  • 기본 고딕 폰트를 사용해 어느 컴퓨터에서나 글씨가 깨지지 않음

🔑 핵심 용어 & 요약

  • DOM: 자바스크립트가 HTML 태그를 조종할 수 있게 연결해주는 구조
  • 환각 현상: AI가 가끔 없는 사실을 진짜처럼 지어내는 현상
  • 요약: 기초 웹 문법을 익히고, AI를 올바르게 구분해 활용한 포트폴리오
