02. DEFINITION

프롬프트 공학이란? (이란)

고차원 임베딩 공간에서 AI가 '가장 가까운 정답 좌표'를 찾도록 유도하는 입력 설계 절차

🧭 핵심 원리: 다차원 공간의 좌표 지정

LLM(대규모 언어 모델)은 입력된 텍스트와 의미적으로 가장 가까운(유사도가 높은) 다음 단어를 예측합니다. 조건이 부족하면 평범한 평균치 답변이 나오지만, 학번·과목·목적·형식 등 좌표를 구체화하면 의도에 가장 근접한 결과물이 도출됩니다.

  • 비유: FPS 게임에서 대충 쏘는 것과, 거리와 이동 경로를 계산해 정조준하는 것의 차이

🧱 프롬프트 구조화 4단계 절차

[1단계: 역할(Role)]    웹프로그래밍 강의 발표용 포트폴리오 설계자
[2단계: 맥락(Context)] 소프트웨어학과 2학년(2022564018 박준혁), 50분 내 제작
[3단계: 지시(Task)]    직접 작성 코드와 참조·AI 코드의 저작권을 구분하여 구성
[4단계: 형식(Format)]  오프라인 USB 실행 가능한 단일 HTML 웹사이트 형태로 출력
03. FUNCTIONS & REASONS

기능 (특징 · 장단점 · 차이점 · 이용) 및 도입 이유

단순 질문과 구조화된 프롬프트의 차이점 및 활용 목적

특징 & 장점 & 단점

  • 특징 (CoT · Few-shot): 단계별 추론과 예시를 제공해 논리적 정확도를 높임
  • 장점: 빠른 화면 초안(프로토타입) 제작, 1:1 코드 해설 및 오타 디버깅 보조
  • 단점: 환각(Hallucination) 발생 가능성, 이해 없이 복붙할 경우 저작권 및 유지보수 문제
  • 이용: UI 레이아웃 초안, 개념 요약 정리, 테스트용 예제 생성

이유 왜 프롬프트 공학을 적용했는가?

  • 1. 제한 시간(50분) 내 구현: 수업 시간 안에 기획부터 디자인, 발표 구조까지 한 번에 완성하기 위함
  • 2. 내 수준에 맞는 개념 분류(불류): 여러 실습 예제의 핵심 원리(DOM, BOM, 타이머)를 이해하기 쉽게 정리
  • 3. 실용적 AI 제어 경험: 수학적 모델링 대신 자연어 명세로 소프트웨어를 제어하는 역량 탐색
비교 항목 일반적인 단순 질문 프롬프트 공학 절차 적용
조건 명시 "포트폴리오 사이트 만들어줘" (막연함) 인적사항·발표 루브릭·수준별 난이도·저작권 구분까지 명시
결과물 신뢰도 불필요하게 복잡하거나 출처가 불분명한 코드 출력 직접 이해 가능한 쉬운 예시와 AI 참조 영역을 분리해 출력
04. CASE STUDIES & SIMPLE EXAMPLES

사례 & 예시 (저작권 및 작성 주체 명확 구분)

내가 이해하고 다룰 수 있는 기초 예제(사례 ①)와 AI 생성 실험(사례 ②)을 투명하게 분리했습니다.

사례 ① 기초 웹 실습 교재 참조 및 직접 수정 코드

※ 출처 구분: 웹프로그래밍 수업 예제 코드를 기반으로 구조와 변수를 직접 수정·학습한 결과물입니다.

  • 학습한 핵심: getElementById로 HTML 요소를 찾고, innerText와 style을 바꾸는 DOM 기초
  • 기타 실습: setInterval 디지털 시계, screen.width 해상도 판별
💡 쉬운 예시 1: getElementById 글자 & 색상 바꾸기

버튼을 누르면 이 글자가 바뀝니다!

// 이해하기 쉬운 핵심 3줄 코드
const text = document.getElementById("easyDemoInput").value;
const target = document.getElementById("easyDemoText");
target.innerText = "안녕하세요, " + text + "님!";

사례 ② 프롬프트 공학 실험 AI 생성 프로토타입

※ 저작권 구분: 본인이 직접 코딩한 것이 아니며, LLM에게 조건을 제시해 생성·수정 과정을 실험한 결과물입니다.

  • 실험 A (눈 내리는 샤갈의 마을): getElementByTagName 오타('s' 누락) 수정 및 "내 수준에서 읽을 수 있게 주석과 쉬운 방식으로 바꿔줘"라고 프롬프트 재요청
  • 실험 B (3D 은하계 시각화): 복잡한 수학 수식을 자연어 명세만으로 생성할 수 있는지 테스트한 AI 실험 결과물
💡 쉬운 예시 2: Math.random() 랜덤 번호 뽑기

오늘의 행운 숫자: ?

// 1부터 100 사이의 정수 하나를 만드는 기초 공식
const num = Math.floor(Math.random() * 100) + 1;
document.getElementById("randomDemoText").innerText = "오늘의 행운 숫자: " + num;
05. SETUP & KEY TERMS

설치 및 실행 방법 · 핵심 용어 정리

오프라인 USB 환경 대비 실행 절차 및 발표 필수 용어

⚙️ 설치 및 실행 방법 (Environment Setup)

  • 1. 파일 구성: HTML, CSS, JavaScript가 모두 포함된 단일 파일(portfolio_site_2022564018.html)
  • 2. 설치 불필요: 별도 프레임워크나 외부 CDN 인터넷 연결 없이 100% 로컬 구동
  • 3. 실행 방법: USB 메모리에 저장 후 Chrome / Edge 브라우저로 더블클릭 실행
  • 4. 폰트 및 캡처 대비: 시스템 기본 고딕 폰트 폴백 적용, Alt + PrintScreen 캡처 시 가독성 유지

🔑 핵심 용어 (Key Terms)

  • DOM (문서 객체 모델): HTML 태그를 자바스크립트가 조작할 수 있도록 객체화한 구조
  • BOM (브라우저 객체 모델): window, screen, navigator 등 브라우저 창과 화면 정보를 다루는 객체
  • 임베딩(Embedding): 텍스트의 의미를 다차원 벡터 좌표로 변환해 유사한 결과를 찾는 원리
  • 환각(Hallucination): AI가 사실과 다르거나 존재하지 않는 코드를 그럴듯하게 생성하는 현상
